# Tests

Everything here runs headless (no window, no sound, your real saves are never touched) and is repeatable:
the emulation is deterministic and every run starts from a fresh, empty save. You need your own ROM at
`rom/smas.sfc`.

## Build
| File | What it is |
|---|---|
| `build_game.sh` | Builds the game into `build-game/` (the working-tree CMakeLists + `smas_stats.c`). Run it after every `tools/regen.sh`. |
| `extras_build.cmake`, `smas_stats.c` | Adds a test-only counter to that build. Not part of the shipped game. |

## Routes (input scripts the game host reads; each starts from power-on)
Generated by `python3 tests/gen_routes.py` (edit the pieces there, not the text files).
| Route | What it does |
|---|---|
| `route_attract.txt` | 4000 frames, no input: power-on, title, the Super Mario Bros. demo. |
| `route_smb1.txt`, `route_ll.txt`, `route_smb2.txt`, `route_smb3.txt` | Select Game -> that game -> File A -> its first level, then run right and jump. Screenshots `title`, `start`, `p01`.. |

## Native code
| File | What it does |
|---|---|
| `coverage_iterate.sh` | One round: promote what the interpreter still ran (banks $01-$0F only), regenerate, keep shared code in the interpreter (`keep_shared_lle.py`), rebuild, run every route with coverage, then the Snes9x picture gate (`ref/gate.py`). Stops with an error if any picture got worse. |
| `coverage_check.sh`, `promote_from_coverage.py` | The measuring and promoting halves of a round. |
| `keep_shared_lle.py` | Adds `force_lle` lines to `recomp/bank00.cfg` for any shared cart code a promotion pulled into translation. Translated shared code breaks Super Mario Bros. 2 and 3 (`notes/native-coverage.md`). |
| `native_share.sh` | How much of the game's real work runs as recompiled code (each route run all-interpreter and normal). |
| `interp_regions.py`, `lle_report.py`, `fn_info.py`, `exit_modes.py`, `jmptable.py`, `dis.py` | Reading aids: which stretches the interpreter still runs, refused functions, one routine's exits, a jump table, a disassembly (`dis.py 20:FB1F 40`). |
| `tier_check.sh`, `compare_tiers.py`, `logic_digest.py` | Proves recompiled code and the original code in the interpreter play the same game. |
| `check_baseline.sh`, `record_baseline.sh`, `baseline/` | Re-checks the current build against the saved recording. |

## Cheats and memory
| File | What it does |
|---|---|
| `ram_search.py` | Finds counters in a run's memory snapshots (`down` mode) or prints addresses over time (`show`). |
| `../notes/ram-map.md` | Every address the cheats use, with how it was proven. |

## Checking against a trusted emulator
| File | What it does |
|---|---|
| `ref/` | A tiny runner for the Snes9x core plus compare, side-by-side, strict-compare and gate scripts. See `ref/README.md`. |
| `contact_sheet.py` | Glues screenshots into one picture. |
